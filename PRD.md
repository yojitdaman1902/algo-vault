# Signature features MVP

Goal: Experience the interview. Understand your mistakes. Beat your past self.

Time Machine provides a strict-filter, three-question historical-style practice round with genuine deterministic scores. Code Autopsy explains supported answer mistakes through verified traces. Ghost Mode compares genuine saved attempts with replayable interaction timelines.

Scope: five curated variants, two specific diagnostic demonstrations, local-only history, demo/practice timing, responsive stacked/split panels, existing workspace retained.

Non-goals: authenticated historical interviews, code execution, AI diagnosis, backend, account sync, active session recovery, automatic modification of practise completion.

Acceptance journey and remaining runtime checks are in README.md and TASKS.md. Entry for tracked standalone questions is the Time Machine practice library rather than the legacy bank detail modal.
