# DOC-04 — User Quickstart

1. **Find your next question.** AlgoVault organizes DSA practice for exams and placements. Enter the workspace using an offered year, then open **Question Bank**. All questions are available; year-based recommendations are not implemented.
2. **Tell it what you need.** Search a title/keyword or open **Filters** for subject, semester, paper year, topic, company-style tag, and difficulty. Filters work together. Open a title or View to read the question and example.
3. **Track and revise.** Click the practice circle when finished. Progress updates throughout the app. Pin unanswered or Hard questions; **Revise Next** holds up to five. **Mark Practised & Clear** completes one and frees its slot. **Remove from Queue** only removes it.
4. **Recover safely.** Click the practice circle again to undo a mistaken completion. Use **Clear Filters** if nothing matches. Remove a queued item to free capacity; re-pin it if still unanswered or Hard. Refresh retains saved progress when browser storage is available. Do not clear browser storage unless you intend to delete that progress.

All paper associations and company tags are demonstration data. Optional Time Machine, Code Autopsy, and Ghost Mode are local practice simulations, not real company assessments or code execution.
